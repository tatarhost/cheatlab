**Почтовый раздел:** https://cheatlab.fun/mail

CheatLab Mail — почтовый интерфейс для адресов `@cheatlab.fun`, связанный с
аккаунтом CheatLab. Интерфейс использует отдельный API Worker и базу D1.
GitHub Pages сам по себе не принимает и не отправляет почту.

## Что уже реализовано в интерфейсе

1. Создание до пяти почтовых адресов на аккаунт.
2. Входящая почта.
3. Папка отправленных писем.
4. Избранные письма.
5. Поиск по отправителю, теме и тексту.
6. Обновление списка писем.
7. Отметка письма прочитанным.
8. Добавление и удаление из избранного.
9. Просмотр HTML-писем в изолированном iframe.
10. Отображение удалённых HTTPS-изображений в HTML-письмах (при условии, что отправитель передал HTML с корректным `img src`, а CDN разрешает загрузку).
11. Поиск кода подтверждения в теме, обычном тексте и HTML-тексте.
12. Кнопка копирования кода подтверждения.
13. Ответ на входящее письмо.
14. Создание и отправка письма.
15. Прикрепление до пяти файлов к исходящему письму в установленных лимитах.
16. Выбор опубликованного проекта CheatLab и вставка ссылки в письмо.

## Важное про изображения

DeepSeek banner выше добавлен в Markdown-описание как внешнее изображение.
В письмах удалённая картинка появится только если в сохранённом HTML письма
есть корректный HTTPS-адрес в `<img src="...">`. Если письмо использует
`cid:`-ссылку на встроенное MIME-вложение, одной загрузки картинки по HTTPS
недостаточно: потребуется отдельная поддержка Content-ID и безопасная выдача
входящего вложения через Worker.

Некоторые почтовые сервисы блокируют внешние изображения или требуют
подтверждения их показа. Это решение на стороне получателя или CDN, и сайт не
может принудительно обойти такую блокировку.

## Анимации

Почтовый интерфейс получил мягкое появление панелей и строк, небольшие реакции
кнопок и отдельное появление карточки кода. При включённой системной настройке
уменьшения движения анимации отключаются.

## Развёртывание

- Изменения `public/` публикуются через GitHub Pages.
- Изменения `worker/` требуют отдельного `wrangler deploy`.
- Изменения схемы данных требуют применения миграций D1.
- Не публикуйте API-ключи Resend, webhook-секреты или токены Cloudflare в Git.

Это описание не означает, что все пункты со статусом «План» уже доступны.
